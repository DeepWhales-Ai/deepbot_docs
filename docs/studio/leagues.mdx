<H2 id="league">The League</H2>
<Para>
  <strong>Share a hunt</strong> and it enters the weekly <strong>League</strong>. Hunts
  are ranked by <strong>median return</strong>, the typical result across their trades,
  so one lucky trade can't top the table.
</Para>

<H2 id="competitions">Weekly competitions</H2>
<Para>
  <strong>Weekly competitions</strong> run on top of the League, with a fresh table every
  week.
</Para>

<H2 id="winners-room">The Winners Room</H2>
<Para>
  <strong>The Winners Room</strong> shows the community's shared hunts. Open one to see
  how it is set up and how it has done. On PRO you can <strong>copy</strong> it into your
  own Studio, then run it on paper or live.
</Para>
<Para>
  Shared hunts show a display name, never your wallet.
</Para>
