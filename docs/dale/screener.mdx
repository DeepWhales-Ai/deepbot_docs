<H2 id="what">What it does</H2>
<Para>
  Define buying criteria in conversation. Dale evaluates the live market against
  those criteria continuously and delivers a match by DM. The screener runs on
  Ethereum, BSC, Base and Solana. Polygon is not part of this release.
</Para>

<H2 id="criteria">What you can screen for</H2>
<Para>
  Chain, minimum liquidity, minimum age, minimum holder count, maximum developer
  wallet concentration, LP burn threshold, safety verdict tolerance. Create,
  update, pause, resume, delete and view every screener through Dale. Ask Dale to
  suggest criteria if you don't have a strategy in mind, then refine in
  conversation.
</Para>

<H2 id="entitlements">Entitlements</H2>
<Para>
  Free accounts run one active screener. Pro accounts run up to five.
</Para>

<H2 id="match">What a match looks like</H2>
<Para>
  Every match DM carries everything needed to decide without leaving the message:
</Para>

<KeyValueGrid items={[
  { k: "Risk verdict", v: "Benign, warning, or malicious / unverified." },

<H2 id="before">Before delivery</H2>
<Para>
  Matches are filtered before delivery, not after.
</Para>
<Para>
  On EVM, every match clears a hard minimum LP burn floor of 90 percent from
  Blockaid data. A token with missing or failed burn data is rejected, not passed
  through.
</Para>
<Para>
  On Solana, every match clears a developer wallet holding cap before delivery.
</Para>
