<H2 id="chains">Supported chains, every exit type</H2>
<Para>
  Stop loss, trailing stop and tiered take profit run on Ethereum, BSC, Base and
  Solana. Solana runs the same three exit types as the EVM chains.
</Para>
<Callout kind="info" title="Polygon">
  Polygon does not currently support automated exits.
</Callout>

<H2 id="what">What each does</H2>
<KeyValueGrid items={[
  { k: "Stop loss", v: "Triggers a sell if price falls below a set level." },
  { k: "Trailing stop", v: <>Follows the price upward and triggers if the trailed floor is broken. The trail percentage is set at arm time and evaluated against live prices every 30 seconds.</> },
  { k: "Tiered take profit", v: "Places multiple price targets, each with its own exit size, on one position." },
]} />
<Para>
  All three can run on the same position at once, each managed independently.
</Para>

<H2 id="entitlements">Entitlements</H2>
<Para>
  Automated exits are a Pro capability across the supported chains (Ethereum, BSC,
  Base and Solana), whether set manually on a held position or armed automatically
  as part of a buy. Up to five armed strategies per user.
</Para>

<H2 id="armed">Armed against the real position</H2>
<Para>
  When an exit is armed by token name, Dale resolves the exact token from live
  wallet holdings, not from cached reference. Exits are armed against what is
  actually held.
</Para>

<H2 id="fire">When the market gets there</H2>
<Para>
  Every exit is checked against real on chain holdings at fire time. If holdings
  data is temporarily unavailable, the exit holds and retries rather than firing
  on assumed state.
</Para>

<H2 id="sizing">Correct sizing on auto armed exits</H2>
<Para>
  When a buy on BSC or Base arms an exit automatically as part of the trade, the
  exit is sized to the actual quantity bought.
</Para>
