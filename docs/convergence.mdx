<Para>
  Convergence is how DeepBot identifies which tokens are getting attention across the network
  right now. It is not a price prediction. It is not a buy signal. It's a live read on
  what is converging across independent data streams.
</Para>

<H2 id="pillars">The four pillars</H2>
<Para>
  Every token score is a weighted blend of four pillars. Each pillar fills as
  evidence accumulates.
</Para>

<FeatureGrid items={[
  {
    sym: "◢",

  },
  {
    sym: "◥",

  },

<Para>
  Infrastructure assets are excluded from the board. Stablecoins, wrapped natives,
  LSTs, LP tokens and known router infrastructure never appear, so discovery tokens
  are not buried under things everyone already holds.
</Para>

<Callout kind="info" title="Solana routing">
  Solana addresses are handled with case preserved end to end, so a tap to trade
  from the board routes to the correct token.
</Callout>

<H2 id="safety-badge">The safety badge</H2>
<Para>
  DeepBot scans every token through Blockaid, an independent safety service. Coverage
  includes Solana. The badge tells you what Blockaid returned at scan time. A token comes
  back as safe, flagged with warning, or malicious.
</Para>

<KeyValueGrid items={[
  { k: "✅  Safe",                v: "No risk patterns detected at scan time." },
  { k: "⚠️  Flagged with warning", v: "Risk patterns present. Read details before trading." },
  { k: "🚫  Malicious",           v: "Confirmed malicious patterns." },
]} />

<Callout kind="warn" title="This is a snapshot">
  Tokens can change between scans. The deployer can ratchet taxes, drain liquidity, or modify
  the contract. Always recheck before sizing up.
</Callout>

<H2 id="moat">What we don't tell you</H2>
<Para>
  Some details of how the network detects convergence stay private. That includes how
  groups are weighted, how signal strength is measured, which routers we monitor, and which
  patterns we track. <Lime>This is the moat. The data is the product.</Lime>
</Para>
<Para>
  What you get is the output: a score, the pillar breakdown, the safety status. What we keep
  is the method.
</Para>

<H2 id="important">Important</H2>
<Callout kind="info" title="Detection layer, not a recommendation">
  High convergence does not mean a token will go up. It means many independent signals are
  pointing at it right now. Use that as one input. Do your own work on the rest. Nothing on
  this page is financial advice.
</Callout>
